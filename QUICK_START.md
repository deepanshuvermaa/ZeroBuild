# 🚀 Quick Start Guide - Landing Page Builder

## 1️⃣ Start All Services (Run these 3 commands in separate terminals)

### Terminal 1 - Builder App
cd builder-app
npm run dev
Opens at: http://localhost:5176

### Terminal 2 - Client Template  
cd client-template
npm run dev
Opens at: http://localhost:5175

### Terminal 3 - Build Server
cd builder-app
npm run build-server
API running at: http://localhost:3001

## 2️⃣ Create Your First Website

1. Open http://localhost:5176
2. Click "Templates" button
3. Choose a template
4. Click "Use Template"
5. Start editing!

## 3️⃣ Generate Production Build

1. Click Settings → Fill Client Name & Project Name
2. Click Generate button
3. Wait 10-30 seconds
4. Get ready-to-deploy files!

## 4️⃣ Deploy to cPanel

1. Find build in: builder-app/builds/{ClientName}-{Date}/
2. Upload all files to cPanel public_html
3. Done! 🎉
