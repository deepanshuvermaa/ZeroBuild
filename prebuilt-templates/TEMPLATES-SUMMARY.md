## 🎯 Key Configuration Points

Every template has these customizable sections:

### 1. Global Settings
```json
{
  "whatsapp": { "number": "YOUR_NUMBER" },
  "colorScheme": { "primary": "#HEX_COLOR" },
  "fonts": { "heading": "Font Name" }
}
```

### 2. Sections Array
Each section represents a page component:
- Hero
- About
- Services/Menu
- Gallery
- Testimonials
- CTA
- Footer

### 3. Animation Properties
Every section can have:
```json
{
  "animation": {
    "type": "fadeInUp",
    "duration": 0.8,
    "delay": 0.2
  }
}
```
